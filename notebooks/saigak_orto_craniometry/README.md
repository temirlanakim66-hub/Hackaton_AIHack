# Сайгак-Орто — Система 3D-краниометрии и оценки деформаций головы младенцев

Прототип программного продукта с машинным обучением для стандартизированной обработки одного 3D-скана головы младенца (0–18 месяцев), автоматического поиска анатомических ориентиров, детерминированного расчёта краниальных индексов (`CI`, `CVA`, `CVAI`) и формирования клинического PDF-отчёта врача.

## 2. Методика измерений и классификация (Раздел 6 ТЗ)

### 2.1. Анатомические ориентиры и система координат черепа
1. **Опорные ориентиры (`Landmarks`)**:
   - `Sellion (Se)` — наиболее глубокая точка переносья (назофронтальный переход).
   - `RightTragion (TrR)` — верхний край козелка правого уха.
   - `LeftTragion (TrL)` — верхний край козелка левого уха.
   - `Subnasal (Sn)` — подносовая точка (контрольный ориентир лицевого профиля).
2. **Каноническая система координат черепа**:
   - **Начало координат $O$**: середина битрагиального отрезка $O = \frac{Tr_R + Tr_L}{2}$.
   - **Базовая плоскость ($Z_{\text{local}} = 0$)**: плоскость, проходящая через три точки $(Se, Tr_R, Tr_L)$.
   - **Переднезадняя ось $\vec{e}_{AP}$ ($+Y_{\text{local}}$)**: единичный вектор в базовой плоскости от $O$ через точку `Sellion`.
   - **Вертикальная ось свода $\vec{e}_{CC}$ ($+Z_{\text{local}}$)**: нормаль к базовой плоскости, направленная к макушке (`Vertex`, $Z_{\max}$).
   - **Поперечная ось $\vec{e}_{ML}$ ($+X_{\text{local}}$)**: вектор $\vec{e}_{CC} \times \vec{e}_{AP}$, строго перпендикулярный сагиттальной линии в базовой плоскости.
3. **Измерительное сечение (`Measurement Plane — Level 3`)**:
   - Плоскость, параллельная базовой плоскости на высоте $Z_{\text{slice}} = 0.30 \cdot H_{\text{vault}}$ (30% высоты свода черепа над базовой плоскостью — `Level 3` из 10 уровней по протоколу STARband / Graham et al., 2020).
   - Пересечение полигональной сетки плоскостью $Z_{\text{local}} = Z_{\text{slice}}$ формирует замкнутый 2D-контур сечения. Центр измерительных осей в сечении располагается на пересечении середин переднезаднего ($L$) и поперечного ($W$) габаритов контура.

### 2.2. Формулы расчёта краниальных индексов
- **Краниальный индекс ($CI$)**:
  $$CI = 100 \times \frac{W}{L} \quad (\%)$$
  где $W$ — поперечная ширина головы (мм), $L$ — переднезадняя длина головы (мм) в измерительном сечении. До утверждения возрастного профиля экспертом выводится численно без автоматической степени тяжести.
- **Асимметрия свода черепа ($CVA$)**:
  $$CVA = |D_1 - D_2| \quad (\text{мм})$$
  где $D_1$ и $D_2$ — длины диагоналей сечения под симметричными углами $\pm 30^\circ$ к переднезадней оси ($AP$).
- **Индекс асимметрии свода черепа ($CVAI$, основная метрика по исследованию STARband [2])**:
  $$CVAI = 100 \times \frac{|D_1 - D_2|}{\max(D_1, D_2)} \quad (\%)$$
  *(В качестве отдельной явно маркированной справочной метрики также рассчитывается $CVAI_{\min} = 100 \times \frac{|D_1 - D_2|}{\min(D_1, D_2)}$).*

### 2.3. Шкала степени асимметрии по CVAI (Graham et al., 2020 [2])
Категория определяется строго по **неокруглённому** значению $CVAI$:
| Интервал CVAI | Степень выраженности асимметрии | Код |
| :--- | :--- | :--- |
| $CVAI < 3{,}5\%$ | Ниже порога асимметрии по шкале | `NORMAL` |
| $3{,}5\% \le CVAI < 6{,}25\%$ | Лёгкая степень асимметрии | `MILD` |
| $6{,}25\% \le CVAI < 8{,}75\%$ | Умеренная степень асимметрии | `MODERATE` |
| $8{,}75\% \le CVAI < 11{,}0\%$ | Тяжёлая степень асимметрии | `SEVERE` |
| $CVAI \ge 11{,}0\%$ | Очень тяжёлая степень асимметрии | `VERY_SEVERE` |

## 3. Разделение данных и воспроизводимое обучение ML-компонента (Разделы 5.1, 7.1, 8.1)

Состав выборки задокументирован в [`data/dataset_split.json`](data/dataset_split.json):
1. **Обучающая выборка (`Train`)**: 80 анонимизированных 3D STL-сканов (`scan_001.stl` .. `scan_080.stl`, по одному скану на ребёнка). Аугментации (3D-шум и морфологические вариации с фиксированным `seed=42`, расширение с 80 до 320 примеров) выполняются **строго внутри обучающей части**.
2. **Закрытая тестовая выборка (`Reserved Test`)**: 25 анонимизированных 3D STL-сканов (`scan_081.stl` .. `scan_105.stl`), зарезервированных до обучения и не используемых для настройки модели.
3. **Клинические демонстрационные случаи деформаций и дефектов**:
   - `clinical_normal_N01.stl` — нормальная форма головы ($CVAI = 1{,}29\%$)
   - `clinical_mild_plagio_P01.stl` — лёгкая плагиоцефалия ($CVAI = 5{,}14\%$)
   - `clinical_moderate_bp_BP05.stl` — умеренная брахи-плагиоцефалия ($CI = 92{,}35\%, CVAI = 6{,}93\%$)
   - `clinical_severe_plagio_P03.stl` — тяжёлая плагиоцефалия ($CVAI = 9{,}32\%, CVA = 10{,}30\text{ мм}$)
   - `clinical_very_severe_plagio_P04.stl` — очень тяжёлая плагиоцефалия ($CVAI \ge 11{,}0\%$)
   - `clinical_brachycephaly_B01.stl` — симметричная брахицефалия ($CI = 90{,}67\%$)
   - `clinical_scaphocephaly_S01.stl` — скафоцефалия / долихоцефалия ($CI = 73{,}49\%$)
   - `defect_incomplete_occipital.stl` — неполный скан с отсутствующим затылочным сектором (тест отказа)
   - `scale_test_meters_scan082.stl` — скан в метрах (тест калибровки масштаба `×1000`)
